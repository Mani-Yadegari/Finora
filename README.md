# Finora

A modern personal finance dashboard built with the MERN stack.

## 🚀 About

Finora is a premium personal finance management application designed to help users track expenses, manage income, analyze spending habits, and gain better control over their finances through a clean and intuitive interface.

## ✨ Planned Features

* Authentication & Authorization
* Dashboard Overview
* Income & Expense Tracking
* Categories Management
* Budget Planning
* Financial Analytics
* Interactive Charts
* Dark & Light Theme
* Responsive Design

## 🛠️ Tech Stack

### Frontend

* React
* TypeScript
* Vite

### Backend *(Planned)*

* Node.js
* Express
* MongoDB
